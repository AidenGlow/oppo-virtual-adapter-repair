# v1.9：自动查找 YAML 备份

本版支持两种可独立选择的修复方式：OPPO 指定 DLL 改名，以及 Clash / Mihomo TUN 联网网卡配置。使用中文原生 Windows 界面，自动定位目标文件，保留备份、用户选择与最终确认。

本版新增：点击“恢复 YAML 备份”后，自动列出当前配置同目录的对应备份，按时间从新到旧排列；由用户选择并最终确认后恢复。保留“手动选择文件…”备用入口。打开、刷新或取消都不会修改文件，恢复前会另存当前配置。

完整回归 50 项测试及 31 个模糊测试种子通过，1 项权限相关测试跳过。临时配置的“修复 → 自动发现备份 → 恢复”完整闭环通过，恢复前后字节及 SHA256 一致。真实手机和网络效果仍待联调。

使用 Windows 10 / 11 64 位系统，直接运行 EXE。DLL 修改与恢复均需重启电脑；配置修改与恢复前请完全退出代理客户端，完成后重新打开。

详细步骤见 [使用说明](使用说明.md)，验证范围见 [测试结果](../TEST_RESULTS.md)。
