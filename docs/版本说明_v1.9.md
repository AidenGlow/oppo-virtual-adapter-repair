# v1.9 发布版

针对安装 OPPO 互联后，Clash / Mihomo 开启 TUN 就断网的情况，提供两种可自行选择的修复方式：OPPO DLL 修复，或指定 TUN 实际联网网卡。自动识别 OPPO 安装位置、Clash Verge Rev 和 Clash for Windows 配置。

- 简洁中文界面，支持高 DPI 和调整窗口大小。
- 自动查找当前 YAML 对应备份，按时间列出，由用户选择并最终确认后恢复；保留手动选择入口。
- 修改前备份，恢复前另存当前配置；只打开界面、识别文件或取消确认不会修改配置。
- 补充 OPPO 虚拟网卡与 TUN 断网案例，以及两种修复方式的作用说明。

## 下载和使用

打开 [v1.9 Release](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/tag/v1.9)，在 Assets 中下载 `.exe` 直接运行；完整包内含程序、源码及中文说明。Windows 10 / 11 64 位。`SHA256.txt` 可核对两个附件。

DLL 方式需先登录并连接手机，修复或恢复后重启电脑。配置方式需先完全退出代理客户端，完成后重新打开。如遇问题可点击恢复，并保留原目录中的备份文件。
