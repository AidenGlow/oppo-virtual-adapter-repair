# 发布附件与固定下载地址

对外以当前稳定版作为统一下载入口。仓库首页和 Release 介绍工具解决的问题、两种修复方式及下载 / 恢复方法；逐项更新记录放在 `CHANGELOG.md`，测试细节放在 `TEST_RESULTS.md`。调整介绍文字时保留已有版本标签和附件，不因此增加程序版本。

首页使用 GitHub 的 `releases/latest/download/文件名` 地址，自动跟随被设为最新版的正式 Release。后续版本固定上传以下三个附件，不在附件名中加入版本号：

- `oppo-virtual-adapter-repair-windows-amd64.exe`
- `oppo-virtual-adapter-repair-windows-amd64-full.zip`
- `SHA256-latest.txt`

版本号由 Release 标签和程序内版本信息记录。这样首页下载链接无需随版本修改。GitHub 的地址规则见[官方说明](https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases)。

完成该版本构建、完整包和验证后，在项目根目录执行：

```powershell
$version = [regex]::Match((Get-Content -LiteralPath 'source/version.go' -Raw -Encoding utf8), 'const appVersion = "([^"]+)"').Groups[1].Value
if (-not $version) { throw '无法读取版本号' }
./tools/prepare-release-assets.ps1 -ExePath "./OPPO互联连接修复工具_${version}.exe" -ZipPath "./OPPO互联连接修复工具_${version}_完整包.zip"

gh release create $version './release-assets/oppo-virtual-adapter-repair-windows-amd64.exe' './release-assets/oppo-virtual-adapter-repair-windows-amd64-full.zip' './release-assets/SHA256-latest.txt' --repo 'AidenGlow/oppo-virtual-adapter-repair' --title "OPPO互联占用虚拟网卡修复 · Windows 稳定版（$version）" --notes-file "./docs/版本说明_${version}.md" --latest --draft=false --prerelease=false
```

准备脚本只复制文件并生成 UTF-8 校验清单，会核对复制前后的 SHA256。发布命令始终上传相同名称的附件，并将正式版本设为最新发布。发布后用首页的三个固定地址实际下载，核对 SHA256、完整包和包内 EXE。

v1.9.2 为兼容已有链接，同时保留带版本号的旧附件；固定名称附件与原附件内容相同。
