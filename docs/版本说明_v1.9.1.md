# v1.9.1 发布版：双击自动请求管理员授权

双击 EXE，Windows 会自动弹出管理员授权窗口，点击“是”后进入工具，无需再寻找“以管理员身份运行”。普通账户需要电脑管理员授权。

- 保留 OPPO DLL 修复和 Clash / Mihomo 配置两种独立方式。
- 系统授权只负责启动；修复仍需核对路径、相关勾选及最终确认。取消授权则不启动。
- 保留自动查找文件、备份选择、恢复和高 DPI 界面。DLL 被占用或目录有额外访问限制时仍会停止并提示。
- 50 项业务回归、31 个模糊测试种子通过；Windows 原生资源和要求提权（740）检查通过。

下载本页 EXE 直接运行，或下载包含源码和中文说明的完整包；SHA256.txt 可核对两个附件。
