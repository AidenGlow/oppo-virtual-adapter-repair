# GitHub Pages 项目介绍页

页面地址：https://aidenglow.github.io/oppo-virtual-adapter-repair/

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。页面为静态 HTML 和 CSS，`.nojekyll` 跳过 Jekyll 处理，不需要 Node、构建依赖或额外服务。

## 更新页面

- `docs/index.html`：介绍、使用步骤、恢复说明、下载入口和搜索引擎元数据。
- `docs/site.css`、`docs/icon.svg`：响应式布局和站点图标。
- `docs/sitemap.xml`：站点地图；实质更新页面时同步 `lastmod`，使用实际更新日期。
- `docs/indexnow-key.txt`：IndexNow 网站所有权验证文件，必须公开访问，保留 UTF-8 纯文本内容。这不是 GitHub 或 Bing 账户凭据。
- `docs/images/proxy-sample.png`：现有样本截图，供链接分享预览使用。

提交到 `main` 后，GitHub 自动发布。发布状态见仓库 Settings → Pages 或 Actions 中的 Pages 部署记录。部署完成后核对页面、CSS、图标、验证文件与站点地图均返回 HTTP 200。

下载按钮使用 `releases/latest/download/` 和固定附件名。更新 Release 时继续保留 `oppo-virtual-adapter-repair-windows-amd64.exe`、`oppo-virtual-adapter-repair-windows-amd64-full.zip` 和 `SHA256-latest.txt`，页面无需手改版本号。不要为页面文案更新重建 EXE 或移动既有版本标签。

## 向 Bing 提交更新

本项目通过 Bing 支持的 IndexNow 提交页面 URL。验证文件位于项目子目录，`keyLocation` 必须一并提供，且只能提交该项目目录下的 URL。无需 Bing 账号；站长工具账户可另行用于查看搜索表现。

在仓库根目录使用 PowerShell 7：

```powershell
$siteUrl = 'https://aidenglow.github.io/oppo-virtual-adapter-repair/'
$keyText = (Get-Content -LiteralPath './docs/indexnow-key.txt' -Raw -Encoding utf8).Trim()
$keyUrl = $siteUrl + 'indexnow-key.txt'
$onlineKey = (Invoke-WebRequest -Uri $keyUrl).Content.Trim()
if ($onlineKey -cne $keyText) { throw '在线验证文件不匹配，请先完成 Pages 部署。' }
$requestBody = @{
    host = 'aidenglow.github.io'
    key = $keyText
    keyLocation = $keyUrl
    urlList = @($siteUrl)
} | ConvertTo-Json
$response = Invoke-WebRequest -Uri 'https://www.bing.com/indexnow' -Method Post -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($requestBody))
$response.StatusCode
```

HTTP 200 表示 Bing 已接收 URL；202 表示已接收、验证待完成。两者都不代表已经收录，也不保证排名。页面有实质更新时提交一次即可，避免重复提交。提交对象是项目介绍页，不是 GitHub 仓库地址、下载 EXE 或站点地图文件。

`sitemap.xml` 已公开提供。Bing 的正式站点地图提交需要站长工具；本次通过 IndexNow 直接提交首页。项目路径下的 `robots.txt` 不能替代域名根目录的规则，因此本项目不添加无效的 robots 文件。

官方说明：[IndexNow 协议与响应码](https://www.indexnow.org/documentation)、[Bing IndexNow](https://www.bing.com/indexnow/getstarted)、[GitHub Pages 发布源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
