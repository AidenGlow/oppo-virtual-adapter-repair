# v1.9.2 发布版：完善失败提示

本版只完善失败提示，界面布局和原有修复流程保持原样。

- 权限不足或访问受限：提示核对管理员授权、文件权限、只读状态与安全软件拦截记录。
- 文件被占用：针对 DLL / YAML 提示处理占用程序、退出代理托盘 / 编辑器，或保存工作重启后按原操作前提重试。
- 路径失效：提示重新查找 / 识别，或手动选择现存文件；恢复时核对原文件和备份位置。
- 保留相关路径、Windows 错误码、原始错误和已建立的备份路径。DLL“拒绝访问”同时给出权限及占用排查指引。

验证：54 项业务回归、31 个模糊测试种子通过，0 失败；1 项权限相关测试跳过。真实故障均在临时文件上构造，原生备份窗口、go vet、Windows 64 位构建及管理员启动资源检查通过。

下载 EXE 直接运行，或下载含源码和中文说明的完整包；SHA256.txt 可核对两个附件。
