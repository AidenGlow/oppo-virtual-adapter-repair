使用方法

两种方式，按需选择。

独立使用，无需依次执行。
打开界面、识别文件和扫描网卡都是只读操作。

01处理 OPPO 组件

OPPO DLL 修复

将指定 Wintun 文件改名，排查 OPPO 相关组件冲突。

  1. 先登录并连接手机在 OPPO 互联中登录账号，确认手机已连接并保持连接。
  2. 核对文件，确认修复选择“OPPO DLL 修复”，核对自动找到的安装目录，勾选连接确认，再点击修复并最终确认。
  3. 重启电脑工具将 daemon/wintun.dll 改名。按提示重启 Windows，再检查连接效果。
可能遇到

新设备或部分连接方式可能受影响；OPPO 更新后可能需要重新核对。如遇问题可点击“恢复 DLL”，恢复后也需重启电脑。

02指定代理出口

Clash / Mihomo 配置

选择实际联网的 Wi-Fi 或以太网，明确代理出口。

  1. 完全退出代理客户端包括托盘程序。在工具中选择“Clash / Mihomo 配置”，核对识别到的客户端与配置。
  2. 选择网卡，确认修改扫描后按连接状态和设备说明选择物理网卡。不要仅凭列表顺序选第一项；核对预览并最终确认。
  3. 重开客户端，检查生效重新打开代理客户端并开启 TUN，再点击“检查是否生效”，最后打开常用网页确认实际联网。
可能遇到

选错网卡可能断网；换网络、订阅刷新或脚本可能覆盖设置。如遇问题可点击恢复，选择局部撤销或整份恢复。

想了解具体改了什么？查看 YAML 配置
interface-name: "Wi-Fi"  # 换成实际联网网卡的名称
tun:
  auto-detect-interface: false

interface-name 位于顶层，与 tun 同级；tun.device 是 TUN 自身的名称。工具会先备份，再修改对应字段，保留其他配置。

OPPO 互联导致 VPN 失效，这个工具适用吗？

如果指的是 Windows 安装 OPPO 互联后，Clash / Mihomo 开启 TUN 就无法联网，可以用本工具排查。适用范围是电脑上的代理网卡冲突；OPPO 手机上的 VPN 应用问题需要另外排查。

Windows 应该下载哪个文件？

普通用户下载本页的“最新版 Windows EXE”即可。支持 Windows 10 / 11 x64；文件名中的 amd64 包含 Intel 和 AMD 的 x64 电脑。无需安装 Go 或 Python。需要源码与说明可下载完整包；GitHub 的 Source code 是源码包。

只是打开软件，会修改配置吗？

打开界面、自动识别文件、扫描网卡和检查是否生效都是只读操作。修复与恢复需要核对目标并最终确认。

提示文件占用、权限不足或路径失效，怎么办？

文件被占用时，按提示保存工作并正常退出相关程序，工具会尝试显示程序名和 PID。权限不足时核对 Windows 管理员授权；路径失效时重新识别或手动指定文件。详细步骤可在中文说明中查看。

显示“配置已生效”，就一定能上网吗？

这表示当前运行内核采用了相应网卡设置，并已开启 TUN。实际联网还受节点和网络环境影响，请再打开常用网页确认。
