# v1.11.0 发布版：只撤销网卡设置与占用程序提示

**Windows 10 / 11（64 位）用户，请下载 `oppo-virtual-adapter-repair-windows-amd64.exe`。Intel 和 AMD 的 x64 电脑都适用。** 双击后确认 Windows 管理员授权即可使用。

[下载 Windows EXE](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/oppo-virtual-adapter-repair-windows-amd64.exe) · [下载完整包](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/oppo-virtual-adapter-repair-windows-amd64-full.zip) · [SHA256 校验](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/SHA256-latest.txt)

- **只撤销网卡设置：**先退出代理客户端，选择原修复记录，核对预览并最终确认；只还原本工具改过的网卡字段，保留后来修改的节点、规则和其他设置。网卡字段有冲突时停止并提示。
- **显示文件占用程序：**占用失败时尝试显示程序名称、PID 和服务名，方便保存工作后正常退出。查询失败、超时或未识别到程序会明确说明，工具不自动结束进程。
- **保留整份恢复：**“恢复 YAML 备份”继续还原整份配置。两种修复方式仍可自主选择，原有生效检查继续保留。

请将新修复生成的 `.bak` 和旁边的 `.bak.oppo-repair.json` 一起保留；删除工具、重新下载后也能用。v1.10.0 及更早的备份缺少撤销记录，可继续整份恢复。

验证：82 项顶层测试、31 个模糊测试种子通过，0 失败；1 项符号链接测试因权限不足跳过。临时配置“修复 → 后改节点和规则 → 只撤销网卡 → 整份恢复”、真实文件占用进程查询、原生界面与离线 Windows x64 构建通过。

完整记录见 [TEST_RESULTS.md](https://github.com/AidenGlow/oppo-virtual-adapter-repair/blob/v1.11.0/TEST_RESULTS.md)。
