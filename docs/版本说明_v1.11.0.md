**用于排查 Windows 安装 OPPO 互联后，Clash / Mihomo 的 TUN 模式失效、开启即断网或无法联网的问题。** 提供两种自主选择的修复方式，并配备自动查找、备份、恢复和生效检查。

## Windows 用户下载

**Windows 10 / 11（64 位）用户，直接下载 [Windows EXE](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/oppo-virtual-adapter-repair-windows-amd64.exe)。** Intel 和 AMD 的 x64 电脑都适用。双击 EXE，在 Windows 管理员授权窗口点击“是”即可使用。

[下载完整包（程序、源码和中文说明）](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/oppo-virtual-adapter-repair-windows-amd64-full.zip) · [SHA256 校验](https://github.com/AidenGlow/oppo-virtual-adapter-repair/releases/latest/download/SHA256-latest.txt)

## 两种修复方式

| 方式 | 用途与操作前提 |
| --- | --- |
| **OPPO DLL 修复** | 自动查找 OPPO 的 `daemon/wintun.dll`，确认后改名以排查相关组件冲突。先登录 OPPO 互联并保持手机连接；修复和恢复后均需重启电脑 |
| **Clash / Mihomo 配置** | 支持 Clash Verge Rev 和 Clash for Windows，自动定位配置，由用户选择实际联网的 Wi-Fi / 以太网。先完全退出代理客户端，确认修改后重新打开 |

两种方式独立使用，无需依次执行。打开界面、识别配置和扫描网卡均只读，文件修改需要最终确认。配置方式可点击“检查是否生效”，核对运行内核是否采用设置。

## 备份与恢复

- **只撤销网卡设置**：预览并确认后，仅还原本工具改过的网卡字段，保留后来修改的节点、规则和其他设置；字段有冲突时停止。
- **恢复 YAML 备份**：自动按时间列出对应备份，支持手动选择；确认后恢复整份配置，恢复前另存当前配置。
- **恢复 DLL**：恢复原文件名，完成后重启电脑。

请保留原 `.bak` 和旁边的 `.bak.oppo-repair.json`。删除工具后重新下载仍可使用；只有 `.bak` 的旧备份可以整份恢复。文件被占用时，工具会尝试显示相关程序名称和 PID，方便正常退出后重试。
